Visual Vibe Coding · lesson 3

No footage.
A script becomes a finished film.

Use it when you have something to say but nothing filmed. One line of your script is one full-frame scene, from Remotion, HyperFrames, Lottie, shaders or your own file, all called the same way. It checks its own rhythm.

$ npx connect-ai-motion demo
$ npx connect-ai-motion install-skill
made from ten lines of text · this is what demo renders

1

Write lines

One line of the script is one beat. draft picks a scene for each line and only copies words out of it.

2

Check the rhythm

Something new every 3 seconds, each design once, no word the script does not say. Every error says how to fix it.

3

Render both shapes

16:9 and 9:16 from the same storyboard. With your voice, beats start on your words.

Remocn (MIT) is a shadcn-style registry of Remotion components: transitions, backgrounds, scenes, text. A component you add with its CLI is a .tsx file, so it plays here as {"kind": "custom", "component": "./path.tsx"}.

not shipped: add the components you want with the Remocn CLI in your project, then call each one with kind "custom". Wrap it so it reads the SceneProps (r, lf, dur, st); the README shows the five lines.

The whole block and component registry of HyperFrames. After a download, hf-import turns every block into a scene and lists the ones that cannot play frame by frame with the reason.
