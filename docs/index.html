Visual Vibe Coding · lesson 3

No footage.
A script becomes a finished video.

Use it when you have something to say but nothing filmed. One line of your script is one full-frame scene: a chart that draws itself, a line drawing, 3D, your screenshot in a device, a still that moves. Remotion, HyperFrames, Lottie, three.js and shaders are all called the same way, and it checks its own rhythm.

HyperFrames registry (456 items)

statement
hyperframes/registry

The whole block and component registry of HyperFrames. After a download, hf-import turns every block into a scene and lists the ones that cannot play frame by frame with the reason.

download the registry folder of heygen-com/hyperframes (1,685 files, 108 MB; HTML + JSON only is about 10 MB), then run: connect-ai-motion hf-import <folder>. Its images, sounds and 3D files have their own terms, so hf-import copies the block HTML only.

heygen-com/hyperframes · Apache-2.0

Remocn components

statement
remotion/remocn-registry

Remocn (MIT) is a shadcn-style registry of Remotion components: transitions, backgrounds, scenes, text. A component you add with its CLI is a .tsx file, so it plays here as {"kind": "custom", "component": "./path.tsx"}.

not shipped: add the components you want with the Remocn CLI in your project, then call each one with kind "custom". Wrap it so it reads the SceneProps (r, lf, dur, st); the README shows the five lines.
